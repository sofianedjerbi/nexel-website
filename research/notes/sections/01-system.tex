\section*{The system}
\begin{itemize}
\item \textbf{Mind.} A local language model (Qwen3-30B-A3B, 4-bit) reads the game as text every $\sim$20\,s and sets a
goal (gather, craft, ask, build) and, in its own words, the build it wants, kept until it names another.
\item \textbf{Architect.} The same model turns the words into a design (shape, storeys, roof style and materials,
furniture); code draws it in 3D; the game's own judge checks it and a check that it keeps what the words asked; the
model redraws up to 5 times with what failed.
\item \textbf{Executor.} While a drawn build is unfinished it chooses every action: it gathers the bill of materials
(Theorem 1), then lays the cells in an order the game holds (Theorem 2 for stairs).
\item \textbf{Skills.} A gather or craft goal is carried out by code (walk to a source, dig, craft, place a station),
looking further when nothing in view gives the item.
\item \textbf{Body.} A policy trained in the simulator with reinforcement learning (reward: $+1$ the first time each of
$\sim$150 events happens, goal completion with progress shaping, the old hut's judged grade). It now acts only when
nothing above has a step, and unhurt it may move, eat, fight and talk but not craft, place or dig.
\end{itemize}
